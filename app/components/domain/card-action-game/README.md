# StCardActionGame

Componente de card para exibir jogos em destaque com ações (ex.: "Jogar").

## Props

- `title` (string): Título do jogo
- `subtitle` (string): Subtítulo ou provedor do jogo
- `buttonText` (string): Texto do botão de ação
- `to` (string): Link de destino do botão
- `target` (string): Target do link (`_blank`, etc)
- `illustration` (IllustrationName): Nome da ilustração a ser exibida no fundo do card
